# Список задач / Task List

Простой To-Do лист с тёмным glassmorphism-дизайном. Поддержка русского и английского языков.

## Функционал

- ✅ **Добавление задач** — ввод текста и кнопка «Добавить» (или Enter)
- ✅ **Отметка выполненных** — клик по кружку слева от задачи
- ✅ **Удаление задач** — кнопка с иконкой корзины
- ✅ **Редактирование** — двойной клик по тексту задачи или кнопка карандаша
- ✅ **Сохранение после обновления страницы** — задачи хранятся в `localStorage`
- ✅ **Фильтрация** — все / активные / выполненные (боковая панель)
- ✅ **Прогресс-бар** — показывает соотношение выполненных задач
- ✅ **Очистка выполненных** — кнопка «Убрать выполненные»
- ✅ **Переключение языка** — `RU / EN` в шапке, язык сохраняется

## Технологии

- [React 18](https://react.dev/) + TypeScript
- [Tailwind CSS v3](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — иконки
- `localStorage` — хранение задач и настройки языка
- Create React App — сборка

## Запуск локально

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm start
```

Приложение откроется по адресу [http://localhost:3000](http://localhost:3000)

## Production-сборка

```bash
npm run build
```

Готовые файлы окажутся в папке `build/`. Её можно деплоить на Vercel, Netlify или любой статический хостинг.

## Деплой на Vercel

1. Залить репозиторий на GitHub
2. Зайти на [vercel.com](https://vercel.com) → **New Project** → выбрать репозиторий
3. Framework Preset: **Create React App** (Vercel определит автоматически)
4. Нажать **Deploy**

---

> Задачи сохраняются только в браузере пользователя — никакого бэкенда и внешних запросов нет.
